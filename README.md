# Dystiny AI Tradeoff Question Starter

A browser-private aid for shaping a balanced, source-aware AI tradeoff question before deliberately opening a visual Dystiny exploration.

The standalone deployment is retired. Use Dystiny's maintained native [Research Uncertainty Ledger](https://dystiny.com/research-paths/uncertainty/); this repository preserves the earlier browser-private source.

The page stores and sends nothing. The prepared question is passed to Dystiny only after the visitor chooses the answer route.
